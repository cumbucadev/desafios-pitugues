# Contribuindo

[English Version](/CONTRIBUTING_EN.md)

Este repositório abriga desafios a serem solucionados na linguagem de programação Pituguês.

Os desafios podem ser encontrados nas [nossas issues](github-issues) e você também pode trazer novos desafios para o repositório.

## Abrindo Issues

* Se você ainda não estiver familiarizado com o que são as issues, recomendamos a leitura [do capítulo sobre issues](https://git-e-github.para-humanos.cumbuca.dev/8.-issues-no-github/8.1-o-que-e-github-issues) do livro 'Git e GitHub para Humanos'


* Procure fazer uma descrição clara do desafio que deseja propor, trazendo exemplos e os resultados que devem ser gerados.
